# GTKR-RAKSI---GET-TO-KNOW-REAKSI
Get to Know REAKSI (GTKR) merupakan media pengenalan LPM REAKSI Fakultas Sains dan Teknologi UIN Sunan Gunung Djati Bandung. GTKR mengajak mahasiswa mengenal sejarah, struktur organisasi, departemen, program kerja, karya, dan aktivitas REAKSI secara interaktif serta membuka peluang untuk bergabung.
